## 3. 字体、字幕与断行铁律
- **英文 / 数字 / 档案编号**（`FILE.001`、`+13,672★`、`TOP #01`）：等宽体（`JetBrains Mono` / `monospace`）。
- **中文标题与字幕**：超粗黑体（`Noto Sans CJK SC` / `PingFang SC` Heavy）+ 硬像素阶梯阴影，**禁止在小屏中文长句上使用低清糊字点阵字体**。
- **字幕防撕裂铁律**：
  - 单行严格 **≤ 14 字**；
  - 切分字幕时**严禁在英文单词/数字中间断开**（如禁止出现 `带你拆解 G` / `itHub`，必须按 `[A-Za-z0-9]` 整词边界切分）；
  - 满屏大字撞击镜头出现时，**必须隐藏底部字幕**，严禁重叠打架。
