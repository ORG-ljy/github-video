# DESIGN.md — 像素侦探档案（Detective Pixel Case-File）视觉规范 v1.0

> 本文件锁死 `ORG-ljy/github-video` 的全片视觉系统。任何新视频组件必须严格遵守以下规范，不得擅自引入规范外色值、廉价粒子或模板化排版。

## 1. 频道个人特色（IP & 视觉基因）
- **叙事母题**：科技/开源「侦探破案档案」（Case File），借推理片公共视觉语法（红砖钥匙孔、镜片反光、红线线索板、发光放大镜），**严禁使用任何受版权保护的动漫角色外形**。
- **专属原创 IP**：**压低侦探帽檐的像素黑猫剪影**（不露多余五官，仅靠圆框眼镜的一道白色/金色闪电反光表达「灵光一闪 / 破案真相」）。
- **招牌转场**：
  - 开场：**像素红砖钥匙孔推镜（Keyhole Zoom-In）** + `FILE.XXX` 编号卡重拍；
  - 高能反转：**0.5–0.7s 镜片反光 + 像素闪电劈屏**；
  - 结尾：**红砖门合上 + `CASE CLOSED` 印章定格**。

## 3. 字体与可读性铁律
- **英文 / 数字 / 档案编号**（`FILE.048`、`EVIDENCE #01`、`+1,982★`）：等宽像素/硬朗等宽体（`JetBrains Mono` / `monospace`）。
- **中文大标题与字幕**：超粗黑体（`Noto Sans SC` / `PingFang SC` Heavy）+ 硬朗像素阶梯阴影（`4px 4px 0 #000`），**禁止在小屏中文长句上使用糊成一团的低清点阵字体**。
- **字号规范**：满屏撞色大字 `76–96px`；字幕 `44–48px` 单行严格 **≤ 14 字**，杜绝单字折行。

## 4. 9:16 竖屏安全区与互斥规则（`1080×1920`）
- **顶部遮挡区**：`0–130px`（仅放极细进度尺与左上角红钥匙孔角标）
- **右侧遮挡区**：`940–1080px`（避开抖音点赞/评论/转发按钮）
- **核心视觉舞台**：`150–1420px`（主画面必须占满 ≥ 65% 视觉面积，禁止下半屏大片死黑留白）
- **底部字幕区**：`1460–1600px`（避开抖音底部标题/音乐栏 `1640–1920px`）
- **互斥铁律**：**满屏大字撞击镜头出现时，必须隐藏底部字幕**，严禁大字与字幕重叠打架。

## 5. HD-2D 真素材融合与鱼眼限制
- **严禁拿白底 GitHub 代码文件列表当主画面**。
- 真实 README Demo / 界面嵌入像素舞台时，统一叠一层**极轻 CRT 微扫描线 + 放大镜光学暗角**消除割裂感。
- **WebGL 鱼眼镜头严格限定 2.5–3.0 秒**，且封装为「像素侦探放大镜审阅机密档案」样式，仅用于证物高光。

## 6. 音频与卡点铁律
- 所有切换、闪电、证物弹入必须踩在 **真实 BGM 检测出的重拍时间点** 上；
- 前 `0.5s` 必配 1 个短促清脆提示音；关键动作配《纪念碑谷》式干净点音；
- 人声严格遵循 `docs/HARD_RULES.md`（`gain=-6.0`、`48kHz`、`clips=0`、禁用 `boom.wav`）。
