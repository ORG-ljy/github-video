## 一、底层认知：为什么「模板盘点号」死得快，而高赞号能破 30 万赞？

1. **选题方差 ≫ 包装方差**（来自 `liujinyi-vibe` 实查）：同一套包装下，不同选题点赞可差 1000 倍。硬凑「每周 Top 10」必然掺水，小白看到第 3 个相似仓库直接划走。
2. **教程向流量差一个数量级**：讲「怎么安装配置」只有几千赞；讲「**反常识结果 + 背后原理 + 生活类比**」才能冲 30 万–100 万赞。
3. **屏幕上给眼睛看，不是给眼睛读**：
   - **绝对禁令**：严禁拿「白底 GitHub 代码文件列表（`Initial commit / LICENSE / README.md`）」当主画面！
   - 必须展示 **README 真实运行 Demo（GIF/WebP/MP4/效果图）** 或 **为该项目定制的原理矢量动画**。
   - **WebGL 鱼眼仓库页只配给 2.5–3 秒**，定位是「证物高光镜头」（划黄线证明“真开源、真免费、确实涨了这么多星”），绝不当主画面硬撑。
4. **双轨产品形态（拒绝默认硬凑 3 分钟）**：

| 轨道 | 定位 | 黄金时长 | 适用选题 | 流量天花板 |
|---|---|---|---|---|
| **A 轨：单品深度科普（主力冲爆款）** | 用 `Vibe 知识大赏` 六幕结构把 1 个反常识开源神器的**效果 + 原理 + 意义**讲透 | **90–140 秒** | `nospeaker`（触控板唱歌）、`llm.asm`（12KB 跑 AI）、`VIctory`（PC 跑 GTA 6）、`KuroCat`（桌宠黑猫） | **30 万–100 万+ 赞**（强收藏 + 强转发） |
| **B 轨：一周精选速览（稳更新拉粉）** | **只精选 3–5 个**最有画面感的项目，绝不凑数到 10 个；每项 18–25 秒 | **90–130 秒** | 每周 GitHub 飙升榜中通过「选题过滤器」的 Top 3–5 | **1 万–15 万赞**（高稳定收藏 + 转粉） |

## 二、8 步门禁流水线（严禁跳过步骤一次成片）

### 第 0 步：选题过滤器（不通过不写代码）
每个入选项目必须逐条回答 **是/否**（1–3 任一为「否」或 4 为「是」，直接淘汰换题）：
1. **反常识 / 强结果前置吗？**（观众第一反应会说「啊？电脑还能这样？」或「这也能免费开源？」）
2. **有看得见的画面证据吗？**（仓库 README 自带高清 Demo GIF/视频/效果图，**或**能画出极强反差的生活类比矢量动画）
3. **能收成一句小白听得懂、愿意收藏/转发的话吗？**
4. **是否与近期爆款同钩子硬撞车？**（如泛滥的“又一个 Claude Skill 合集”直接淘汰）

### 第 1 步：事实核查与真素材盘点
- 输出**事实清单**：项目名、真实 Star 数、协议（MIT/Apache）、核心指标（如 `2.4 MB`、`12 KB`、`50 ms`），每条必须溯源至仓库 README / 官方页面，**严禁杜撰数字**。
- **素材分级采集**（严格按优先级，严禁跳过 P1 直接用 P4）：
  - **P1 级（最高优）**：自动提取仓库 README 中的真实演示视频 / 动画 WebP / GIF（转码 30fps MP4）
  - **P2 级**：项目专属 MG 概念动画（矢量原理图、3D 堆叠、微交互模拟、Before vs After 数据碾压对比）
  - **P3 级**：高反差满屏大字撞击（Kinetic Typography，用于 1.5–2.5s 情绪转折）
  - **P4 级（仅作 2.5–3s 证物）**：Playwright 真实仓库截图 + **WebGL 鱼眼曲屏 + 荧光黄高光笔**

### 第 2 步：分幕脚本（短句、第二人称、声画分离）
- **A 轨（单品深度）严格执行六幕结构**：
  1. **钩子（0–5s）**：结果前置 / 反常识提问，前 3 秒内完成 **2–3 次快切**（痛点 → 奇观结果 → 悬念）
  2. **概念锚点（~15%）**：一句话用大白话定性它是啥（禁术语堆砌）
  3. **具象论证（~30%）**：真机 Demo + 生活类比，一幕一画面
  4. **硬核内核（~25%）**：用矢量可视化拆解「它凭什么能做到」（让观众觉得“学到了”）
  5. **尺度转折（~15%）**：拉大到行业/普通人切身收益（如“不用买几百块软件 / 老电脑也能跑”）
  6. **升华回扣（最后 8–12s）**：回扣开头悬念 + 仓库搜索词名片 + 弱 CTA（“收藏防走丢 / 发给需要的朋友”）
- **B 轨（一周精选 3–5 项）每项严格三拍**：
  - `真机效果/视觉奇观 (8–12s)` → `撞色大字金句或核心对比 (3–5s)` → `2.5s WebGL 鱼眼证物收尾`
  - **相邻两项强制切换构图顺序与核心动效**，禁止连用同一模板。

### 第 3 步：锁死视觉系统（`DESIGN.md` 铁律）
1. **色板克制**：纯近黑底 `#0A0A0A`（可叠极细 1px 暗网格或细微胶片颗粒）+ **全片仅 1 个霓虹强调色**（黑金 `#E1B98F` / 极客青 `#22D3EE` / 酸橙 `#D4F044` 三选一，一旦选定全片锁死；**永久废除廉价彩色散景圆圈背景**）。
2. **撞色切屏**：仅允许用「主强调色底 + 纯黑超粗字」做 1.5–2.5s 的高能大字切屏，制造强视觉呼吸感。
3. **字体与字号**：全片字体 ≤ 2 种（思源黑体 Heavy + JetBrains Mono）；大字 72–96px，**一屏只讲一个重点**，静音刷到也能 1 秒看懂。
4. **安全区与互斥规则（9:16 竖屏 `1080×1920`）**：
   - 顶部 `0–140px`、右侧 `940–1080px`、底部 `1640–1920px` 为抖音 UI 遮挡区，禁放核心信息；
   - 主视觉舞台必须占满 `160–1400px`（占比 ≥ 65%），消灭大面积死黑空白；
   - **大字与底部字幕严格互斥**：满屏大字镜头出现时自动隐藏底部字幕；底部字幕单行严格 ≤ 14 字，杜绝单字折行。
5. **贯穿主符号**：全片保留 1 个极简视觉主符号（如顶部精细刻度进度条 / 随进度点亮的星轨标尺）。

### 第 4 步：真实 BGM 重拍卡点表（绝不瞎猜 BPM）
- 选定系列固定 BGM（如 [`千年以后-纯音版-BPM112.m4a`](file:///home/antigravity/ORG-ljy/liujinyi-vibe/%E5%8D%83%E5%B9%B4%E4%BB%A5%E5%90%8E-%E7%BA%AF%E9%9F%B3%E7%89%88-BPM112.m4a) 或轻科技节拍）。
- **必须先用程序对实际音频做 onset / beat 检测**，导出真实重拍秒表。
- 输出总表：`镜头号 | 起止秒 | 口播/字幕 | 画面动作 | 对齐重拍点 | 音效`。
- **说到哪出哪**：所有元素按口播真实时间码与重拍点逐个触发，绝不提前整批弹出剧透。

### 第 5 步：音频与《纪念碑谷》式克制音效
- **人声主轨**：严格遵循 [`docs/HARD_RULES.md`](./HARD_RULES.md) 防爆音 6 条铁律（硅基流动 `ljy-hook-clean`、`gain=-6.0`、`wav` 无损获取、`-55dB` 截静音、`48000Hz` 重采样、`amix normalize=0`）。
- **音效策略**：
  - 视频前 `0.5s` 给 1 个短促清脆提示音（拉升 3 秒留存）；
  - 仅在关键动作（数字弹出、高光刷过、切屏撞击、结论定格）配干净短音（钟琴/弹拨/轻扫频/`pop`）；
  - 普通过渡不配音；**永久禁用合成 `boom.wav`**。

### 第 6 步：先做 10 秒验收，再逐段渲染（门禁铁律）
1. **先实现并渲染开头 10 秒**（含黄金 3 秒钩子 + 首个完整镜头），生成内嵌可播 HTML 审片页交由用户验收（节奏、字体、卡点、配色、音质）。
2. 验收通过后，再逐段制作与渲染；哪里不对只改该段，**严禁不经 10 秒验收就一口气硬渲 3 分钟**。
3. **最终渲染出的 MP4 是唯一验收标准**：必须抽帧拼接触表（Contact Sheet）逐镜目检 + 跑 48kHz 波形 `clips=0` 检测。

## 三、交付前 15 条硬性自检清单（全勾才算过关）

- [ ] **选题达标**：通过第 0 步 4 项过滤，无凑数同质项目
- [ ] **黄金 3 秒**：首帧即给结果/奇观，前 3 秒至少 2 次视觉变化 + 前 0.5s 轻提示音
- [ ] **拒绝文件树**：主画面无白底 GitHub 代码文件列表；优先真实 README Demo / 专属 MG 动效
- [ ] **鱼眼克制**：WebGL 鱼眼严格 ≤ 3 秒，仅作证物高光
- [ ] **零模板复读**：相邻镜头构图不同，每 2–3 秒必有全屏视觉变化
- [ ] **极简色板**：纯近黑底 + 单霓虹强调色（无廉价彩色散景圆圈），字体 ≤ 2 种
- [ ] **安全区合规**：无元素被抖音右侧/底部 UI 遮挡，下半屏无大面积死黑留白
- [ ] **大字字幕互斥**：满屏大字出现时底部字幕隐藏；字幕单行 ≤ 14 字无单字折行
- [ ] **声画严密对齐**：所有镜头与卖点按真实口播/BGM 重拍点逐个触发，不提前剧透
- [ ] **事实可溯源**：Star 数、体积、协议、性能指标均与仓库一致，无杜撰
- [ ] **音频零爆音**：`48000Hz` 立体声、`clips=0`、`wrap_jumps=0`、无截断、无吞字
- [ ] **确定性渲染**：无 `Math.random()`、无无限循环、全元素有明确入场动画
- [ ] **合规声明**：片尾或角标注明「内容由 AI 辅助生成」及开源仓库出处
- [ ] **10 秒门禁通过**：先通过 10 秒验收再出全片，并做全片抽帧接触表终检
- [ ] **内嵌可播交付**：提供聊天页可直接播放的独立 HTML 预览 + 1080×1920 无损母版

- **改稿口令**：

  - 画面太像模板 → 强制切一次高反差撞色大字屏。
